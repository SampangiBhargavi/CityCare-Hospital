# CityCare Hospital Website

## About the Project

CityCare Hospital is a responsive hospital website developed using HTML, CSS and Bootstrap.

The website provides information about hospital departments, doctors, medical services, facilities, testimonials, gallery and health tips.

## Pages

- Home
- About Us
- Departments
- Doctors
- Services
- Facilities
- Testimonials
- Gallery
- Blog / Health Tips
- Contact Us

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- Bootstrap Icons

## Features

- Responsive navigation bar
- Modern hospital-themed design
- Department information
- Doctor profiles
- Medical services
- Hospital facilities
- Patient testimonials
- Hospital gallery
- Health tips and articles
- Appointment enquiry form
- Contact and emergency information
- Responsive design for mobile and desktop
